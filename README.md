
# Smart College Website Portal

## D. Y. Patil College of Engineering, Akurdi

### Web Technology – CCE 5 Project

## About the Project

The Smart College Website Portal is a responsive web application developed to provide students and visitors with information about the college.

It brings important college information together in one place through a simple and user-friendly interface.

## Features

- Home page with college introduction
- About section
- Department-wise information
- Course details with expandable sections
- Department-wise faculty directory
- College notices and announcements
- Admission information
- Student enquiry form with client-side validation
- Enquiry storage using localStorage
- Dynamic data loading using JSON and Fetch API
- Hash-based SPA navigation
- Responsive navigation and layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON
- Fetch API
- Browser localStorage

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if it is not already installed.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

## Note

The faculty profiles and notices included in the project are demonstration data. Enquiries are stored locally in the browser and are not sent to a college server.
